# Economics-Class

Materials for Ryan Mayer’s classes at Battery Creek High School (SC).

## Inflation simulation

[inflation-sim/](./inflation-sim) is a classroom web app: **Inflation Year-over-Year, 1926–2026**. Students scrub a century of U.S. prices, purchasing power, and a frozen paycheck.

**Live class URL:** https://animayer.github.io/Economics-Class/

See that folder’s README for how to run it locally and how to project it.

## Constitution board

[constitution-sim/](./constitution-sim) is a projector board for the Constitution unit: three branches, checks and balances, and the Bill of Rights (Amendments I–X), plus short classroom scenarios.

**Live class URL:** https://animayer.github.io/Economics-Class/constitution-sim/

GitHub Pages keeps inflation-sim at the site root and serves this app from the `/constitution-sim/` folder so the inflation URL does not move. See that folder’s README for board shortcuts and deep links.
